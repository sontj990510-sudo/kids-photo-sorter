# Giving Tree public role demo

24시간 공개 체험 주소: https://giving-tree-app.github.io/

이 저장소의 `site/` 폴더는 Giving Tree Version 47의 정적 역할 체험판입니다.

- 원장, 교사, 가족 역할을 브라우저에서 전환해 주요 화면과 권한 흐름을 확인합니다.
- 운영 Supabase, 실제 로그인, 실제 개인정보와 연결되지 않습니다.
- 얼굴 분석 모델과 운영 인증 정보는 공개 산출물에 포함하지 않습니다.
- 기존 사진 분류 도구 소스는 `app/`에 보존되어 있습니다.
